# zkPayslip

Private payroll on Starknet, built on the STRK20 privacy pool: employers run
shielded salary disbursements, and each employee can generate a one-time,
verifier-bound proof of income — without exposing their financial history.

> **Status: in active development.** This repository is a hackathon build
> (Private Sprint — STRK20 privacy apps, implementation of RFP-11 "Private
> payroll"). Contract addresses, benchmark numbers, a live demo, and full
> documentation will land here as the build progresses.
